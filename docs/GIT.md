# Rendus GitHub — parcours management

Le parcours peut être lu dans le navigateur. Pour déposer, suivre [PARTICIPER.md](PARTICIPER.md). Les branches personnelles sont `cas/a` et `cas/b`, créées à partir du nouveau `main` et conservées pendant le parcours. Chacun remplit ses propres fichiers ; le rapporteur ajoute la synthèse des modules dont il a la charge.

Ne pas mélanger les anciennes branches techniques avec les études de cas. Aucune installation de Git ni commande n’est nécessaire. En cas de blocage, rendre un document local selon la modalité annoncée. Le formateur intègre les contributions après revue, pas au milieu d’un raisonnement pour autoriser sa suite.
