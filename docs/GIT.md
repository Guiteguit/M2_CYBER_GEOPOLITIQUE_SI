# GitHub : deux rendus individuels indépendants

Lire les missions sur le `main` actualisé. Pour les nouveaux dossiers, créer `cas-solo/a` et `cas-solo/b` depuis ce `main` ; chacun modifie uniquement son `DECISION_A.md` ou `DECISION_B.md`. Ne pas réutiliser une branche ancienne sans en avoir vérifié les consignes.

Conserver les anciennes branches et les travaux M01. Les citer par lien plutôt que les écraser ou les recopier. Deux pull requests, une par personne, peuvent regrouper le parcours ; elles ne doivent pas être fusionnées pour permettre la suite. Le formateur effectue la revue ensuite. Aucune compétence Git n’est notée ; une remise locale peut remplacer ce dépôt.

Le pas à pas et la gestion des fichiers précédents sont dans [PARTICIPER.md](PARTICIPER.md).
