# Boîte à outils de décision SI

Choisir seulement les tableaux utiles au cas. Ne pas remplir une méthode entière si elle ne change aucune décision.

## Qualifier une information

| Pièce | Ce qui est dit | Fait du cas / déclaration / hypothèse / rumeur | Ce qu’elle permet de conclure | Vérification manquante |
|---|---|---|---|---|
| P… | | | | |

Une promesse fournisseur peut être un fait documentaire (« le fournisseur l’a écrit ») sans être une preuve que la capacité fonctionne.

## Comparer des options

Commencer par les conditions obligatoires. Puis définir au plus quatre critères : utilité métier, moyens, délai, autonomie d’action ou risque résiduel selon le mandat. Si vous utilisez des poids, les faire totaliser 100 % et expliquer les notes. Vérifier si une autre préférence raisonnable change le classement. Une note ne doit pas masquer une information manquante.

## Tenir un registre de risques

| Dépendance et acteur | Scénario possible | Conséquence et durée | Pièce et incertitude | Réponse proposée | Qui accepte le risque restant ? | Réexamen |
|---|---|---|---|---|---|---|
| À compléter | | | | | | |

Ne pas inventer des probabilités ni additionner des conséquences qui se recouvrent. Un risque est un scénario ; il n’est pas forcément déjà réalisé.

## Définir les responsabilités

Pour une décision, nommer une fonction qui tranche, une qui réalise et une qui apporte la preuve. D’autres peuvent être consultées ou informées. Les fonctions peuvent être fictives ; votre binôme prépare la décision sans prétendre que les actions ont déjà été exécutées. Une autorité absente ne délègue pas automatiquement au participant présent.

## Écrire une condition et un indicateur

Une condition utile : « avant l’envoi de D2, le propriétaire autorise le périmètre par écrit ». Un indicateur utile donne une mesure, une source, une fréquence, un responsable et un seuil qui déclenche une action. Le nombre de réunions mesure une activité ; la proportion de scénarios métier effectivement examinés et corrigés peut éclairer une capacité. Aucun indicateur du cas ne certifie une capacité de production réelle.
