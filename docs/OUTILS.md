# Supports nécessaires

Un navigateur pour lire GitHub ou une copie du dépôt, un éditeur ou traitement de texte et une calculatrice suffisent. Aucun environnement technique, laboratoire, terminal, compte cloud ou logiciel payant n’est requis. Les pièces sont des textes et tableaux lisibles hors ligne après téléchargement.

Vous pouvez dessiner une carte, utiliser un tableau ou produire une liste de relations. Les rendus sont évalués sur le raisonnement et les décisions, pas sur le graphisme. Les calculs portent uniquement sur les montants fournis. Aucune recherche externe n’est obligatoire ; une information absente se traduit en question ou en condition.
