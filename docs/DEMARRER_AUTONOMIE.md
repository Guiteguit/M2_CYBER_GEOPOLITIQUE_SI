# M01–M03 : démarrer sans formateur

Vous êtes **deux** et disposez de trois séances de 90 minutes, soit 4 h 30 de travail effectif hors pauses. Aucun cours oral, installation, accord intermédiaire ou fusion GitHub n’est nécessaire pour continuer.

## Avant le bloc

Vérifier l’accès au dépôt ou disposer d’une copie déjà téléchargée, d’un éditeur et d’une calculatrice. L’établissement doit préciser le moyen de remise si GitHub est inaccessible et le contact pour un problème d’accès ou de matériel. Il n’est pas nécessaire de joindre le formateur pour avancer dans l’analyse.

Attribuer A et B une fois. Lire [le contexte](CONTEXTE.md) et [la méthode](METHODE.md). Depuis le navigateur, suivre [PARTICIPER.md](PARTICIPER.md) pour créer `cas/a` et `cas/b` à partir de ce parcours. Une branche par personne suffit pour les dix modules. A consigne les synthèses M01/M03, B celle de M02. Tous deux complètent leur fichier individuel à chaque module.

## Pour chaque séance

Ouvrir la mission, lancer un minuteur et lire les rôles. Écrire une position initiale avant l’échange. Lire les notions et pièces, préparer deux options et une première décision. **À la minute 45**, ouvrir `EVENEMENT.md` vous-mêmes. Conserver le premier plan, puis le réexaminer. Ce fichier est visible : respecter le moment de lecture pour profiter de la mise en situation.

Discuter, compléter la synthèse, utiliser l’auto-vérification et enregistrer, même si tout n’est pas résolu. Passer à [M02](../modules/M02/README.md) puis [M03](../modules/M03/README.md) au créneau prévu. Un désaccord n’empêche pas de continuer.

## Anti-blocage

- Après trois minutes de blocage GitHub ou d’éditeur, rédiger dans un document local avec les titres du rendu. Conserver les fichiers pour remise ultérieure.
- Pour une notion, consulter `NOTIONS.md`, puis les trois niveaux de `AIDE.md`.
- Après cinq minutes de désaccord sans pièce nouvelle, consigner les deux positions et le critère qui permettrait de choisir. Ne pas inventer une information manquante.
- Les recherches Internet ne sont pas nécessaires : les faits à utiliser sont dans les dossiers fictifs. Les demandes de pièces supplémentaires deviennent des conditions de décision.

## Fin de M03

Chacun conserve trois traces individuelles. Vérifier les trois synthèses et remplir ensemble [le bilan du bloc](../rendus/M03/BILAN_AUTONOMIE.md) : décisions, désaccords, questions et liens vers les rendus. Laisser les pull requests ouvertes ; la revue se fera avec le formateur à partir de M04. Les trois modules sont formatifs.
