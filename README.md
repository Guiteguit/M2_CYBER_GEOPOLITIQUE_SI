# M2 Cyber — Géopolitique du cyberespace et stratégie SI

Un parcours de huit modules de 90 minutes, pour trois étudiants : **observer techniquement, confronter les preuves et défendre une décision SI**.

## Commencer

1. Lire le [contexte Asteria](docs/CONTEXTE.md).
2. Ouvrir la [mission M01 — Qui contrôle l’accès à un service numérique ?](modules/M01/README.md).
3. Vérifier les [outils et prérequis](docs/OUTILS.md), puis consulter l’aide seulement si nécessaire.
4. Conserver ses preuves et rédiger l’analyse dans [rendus/M01](rendus/M01/README.md).
5. Présenter le travail dans une pull request selon le [guide Git court](docs/GIT.md).

## Fonctionnement

Chaque séance inclut des hypothèses individuelles, une investigation, une confrontation et une synthèse. Le résultat attendu est une analyse traçable, pas une suite de commandes copiées. Une observation technique ne devient pas automatiquement une preuve de localisation, d’indépendance ou de conformité.

Le dépôt accueille les supports étudiants et leurs travaux. Les corrections et les événements futurs restent hors de ce dépôt. Un autre dossier ou une autre branche du même dépôt ne constitue pas un espace confidentiel pour le formateur.

## Périmètre

Asteria est une entreprise fictive. Les observations de domaines publics sont des études externes ; elles ne décrivent pas son SI réel. Pour M01, utiliser uniquement les noms et opérations prévus dans la [mission](modules/M01/README.md), ou les résultats de secours fournis. Aucun compte payant ni VM n’est nécessaire.
