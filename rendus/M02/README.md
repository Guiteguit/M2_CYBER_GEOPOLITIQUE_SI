# Rendus M02

Compléter sa position dans `individuel/A.md`, `B.md` ou `C.md`, ajouter les preuves choisies dans `preuves/`, puis compléter `SYNTHESE.md` en groupe. Suivre le [guide de classe](../../docs/PARTICIPER.md).

Nommer ses preuves avec participant, date UTC et objet. Une preuve collective peut être déposée une seule fois et citée par tous. Distinguer résultats réels, jeux simulés et résultats attendus non exécutés. Les notes nominatives restent hors de ce dépôt.


## Pendant le bloc autonome

Suivre [DEMARRER_AUTONOMIE.md](../../docs/DEMARRER_AUTONOMIE.md) : une branche par étudiant sur tout le bloc, synthèses M01/M02/M03 respectivement sur les branches A/B/C, sans fusion. Chacun conserve ses trois fichiers individuels. Si un autre guide indique d’attendre une intégration, le protocole autonome prévaut pendant M01–M03.
