# M02 — Votre rendu individuel

Compléter votre [DECISION_A.md](DECISION_A.md) ou [DECISION_B.md](DECISION_B.md), selon votre identité. Vous devez réaliser toutes les analyses attendues dans [la mission](../../modules/M02/README.md). Un seul dossier par personne est demandé ; aucune synthèse commune ni rapporteur.

Les anciens fichiers `SYNTHESE.md` et `individuel/A.md`/`B.md` sont conservés comme traces antérieures et ne doivent pas être remplis en plus. Pour M01 déjà travaillé, les citer suffit ; compléter seulement une explication personnelle manquante. Les [modalités](../../docs/PARTICIPER.md) expliquent comment préserver les branches et documents existants.
