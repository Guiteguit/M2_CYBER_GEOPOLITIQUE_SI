# Rendus M01

Conserver les preuves brutes dans `preuves/`, sa position dans `individuel/A.md`, `B.md` ou `C.md`, et le résultat collectif dans `SYNTHESE.md`.

Nommage conseillé des preuves : `A_YYYYMMDDTHHMMSSZ_nom_type.txt` ou `.json`. Indiquer la date UTC réelle, la requête, la source et le point d’observation. Le préfixe A/B/C évite les collisions ; il n’est pas une identité administrative.

Vous pouvez utiliser les collectes du module par référence sans les recopier. Distinguez alors votre date d’analyse de leur date de collecte. Ne pas ajouter de secrets, de mots de passe, de données d’entreprise ou de traces personnelles à cet exercice sur des ressources publiques.

Le [guide Git](../../docs/GIT.md) indique comment rendre les contributions puis la synthèse. Un problème Git ne dispense pas de conserver le raisonnement ; il est possible de remettre les fichiers au formateur.


## Pendant le bloc autonome

Suivre [DEMARRER_AUTONOMIE.md](../../docs/DEMARRER_AUTONOMIE.md) : une branche par étudiant sur tout le bloc, synthèses M01/M02/M03 respectivement sur les branches A/B/C, sans fusion. Chacun conserve ses trois fichiers individuels. Si un autre guide indique d’attendre une intégration, le protocole autonome prévaut pendant M01–M03.
